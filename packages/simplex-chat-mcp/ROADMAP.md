# Roadmap

What comes next for Claude Code in SimpleX Chat.

## In the app

- Sessions open in a flat layout by default, with the avatar raised and the text using the full width.
- Claude appears as an agent, with the agent avatar.
- Code in messages is highlighted.
- "Read more" folds long messages, at a length you set.
- Long answers arrive as one message.
- Answers appear live as Claude writes them, from the moment it starts working.
- Alerts come only for messages that need you, such as answers and approval requests.
- The desktop app works fully from the keyboard, with shortcuts, including Ctrl+U to delete to the start of the line, and `\` then Enter for a new line, as in Claude Code.

## In your sessions

- One list in the Main group shows every session and its state: working, waiting for you or idle.
- See what Claude is doing while it works, with its code changes as diffs.
- React to a message, and Claude sees your reaction.
- The model, effort and usage of each session show in its description, updated as they change.
- Allow a tool for the rest of a session with one tap.
- Each session is a topic inside one group, not a group of its own.
- Claude can offer choices and other small interactive widgets in the chat.
- Start a new session from the desktop app, in a folder you choose.

## More agents

- Codex and other agents, alongside Claude Code.
