# SimpleX Directory

Welcome to the selected users' communities that you can join via [SimpleX Chat app](https://simplex.chat/downloads).

SimpleX Directory is also available as a [SimpleX chat bot](https://smp4.simplex.im/a#lXUjJW5vHYQzoLYgmi8GbxkGP41_kjefFvBrdwg-0Ok).

Read about [how to add](https://simplex.chat/docs/directory.html) your community.

All listed groups and channels in JSON, with names, descriptions, member counts, join links and activity times: [directory.simplex.chat/data/listing.json](https://directory.simplex.chat/data/listing.json).
