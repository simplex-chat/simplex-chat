AI increases demand for privacy

Surveillance, deplatforming, and online fraud used to require human effort, so they were relatively rare — and most people thought they needed no protection.*

AI removed the effort: it scans messages at scale, deplatforms automatically, and can fake any face, voice, or number. Anyone with a user identifier will now be targeted — so everyone will want protection.

AI agents handling credentials and money increase demand further: an agent whose identity is controlled by a platform can be shut down or turned against its owner.

Everyone will want communication without user identifiers — and only SimpleX network can provide it.

* In 2021, 9% of 16+ year old US residents were victims of identity theft — Bureau of Justice Statistics.

AI made everyone a target

For 150 years, every network required a user identifier to reach you — a phone number, a username, or a key.

This identifier is your fixed address that can be used to surveil, deplatform, or attack you. AI made it automatic and cheap, so everyone is affected now. SimpleX has no user identifiers at all, so users are protected from such attacks — it is the only network built this way.

The AI agents now acting for people need the same — an identity no company can control, on a network without any user identifiers.

How custom UX helps unify messaging

Every network before messaging converged to one protocol — telephony, email, the web.

Messaging is the exception, because each app's experience can't be reduced to a shared protocol.

Once we add custom user experiences in the chat, SimpleX might become the network messaging converges on.
