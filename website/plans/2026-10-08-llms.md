### Markdown versions of site pages

URL rule:

| Page URL | Markdown URL |
|---|---|
| `/` | `/index.md` |
| `/xx/` (language root) | `/xx/index.md` |
| `/x/` | `/x.md` |
| `/docs/x.html` | `/docs/x.md` |
| `/blog/x.html` | `/blog/x.md` |

Sources:

| Pages | Markdown made from |
|---|---|
| English `docs/**/*.md`, `blog/*.md`, `privacy.md`, `token.md` | source text: front matter removed, links made absolute, HTML entities decoded |
| `index`, `why`, `messaging`, `fdroid`, `contact`, `invitation`, `file` (every language) | rendered HTML |
| `crowdfunding`, `crowdfunding-news`, `news`, `livestream`, `blog`, `links`, `directory` | rendered HTML |

Translated docs and blog posts: no Markdown version.

HTML to Markdown markup:

| Markup | Effect |
|---|---|
| `data-markdown-skip` | element left out |
| `<template data-markdown>` | content included only in Markdown |
| `aria-label`, `title`, image `alt` | link text when the link has no text |

Removed from every page: navigation, footer, scripts, buttons, form controls, glossary tooltips.

## Build mechanics

`website/markdown_pages.js`:
- `markdownKind(inputPath, langs)`: `source`, `html` or none
- `markdownUrl(url, langs)`
- `markdownFromSource(inputPath, resolveLink)`
- `markdownTitle(inputPath)`
- `markdownFromHtml(html, pageUrl)`
- `plainText(html)`

`.eleventy.js`:
- transform `markdownPages`: writes the Markdown version next to each qualifying page
- filters: `markdownUrl`, `markdownAlternate`, `markdownSource`, `markdownTitle`, `plainText`
- collection `markdownDocs`

Templates: `src/llms/*.njk`, each with `permalink` and `eleventyExcludeFromCollections: true`.
