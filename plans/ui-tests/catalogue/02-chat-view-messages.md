# UI test catalogue 2: chat view, messages, chat item info

Every user-facing feature of the desktop chat view, compose bar, chat item context menus and item info, mapped to planned tests: **280 test cases in 24 sections, 4 of them `IGNORE`** (see `## Count`). Format, users, CLI-line conventions, Needs codes and overlap ownership follow `00-legend.md`.

Controls without a label today (selection-toolbar delete/forward, status ticks, scroll buttons, call and content-filter buttons, the compose clear-text (x) button, "go to item" buttons, selection circles, and the live-message bolt, which shares the send button's "Send Message" label) get keys in K2 (plan §5.2); rows below that use them assume those keys.

**Conventions**
- The GUI user is **alice**; CLI peers are bob, cath and dan. CLI lines are taken from the named Haskell tests, rewritten for these roles (`00-legend.md`, Users and CLI output).
- `<#` means a timestamped line and `<##` a plain line, as in `H/Utils.hs`.
- Labels in quotes are exact English strings from `strings.xml`; where the app capitalises or formats a string at runtime, the row names the key, and hard-coded literals (such as "//") are cited at their file:line.

**File aliases** (paths per `00-legend.md`):
