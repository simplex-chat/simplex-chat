## Встановлення SimpleX Chat для терміналу

Використовуйте цю команду:

curl -o- https://raw.githubusercontent.com/simplex-chat/simplex-chat/master/install.sh | bash

Дивіться SimpleX Chat Репозиторій GitHub для інструкції з того, як його завантажити чи скомпілювати з вихідного коду.
